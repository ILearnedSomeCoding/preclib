# Risch 符号积分实现计划

本文是面向当前 prec-cpp CAS 的开发设计，不表示下列能力已经实现。目标是在现有积分器之上建立一个具有明确适用域、精确验证和失败语义的 Risch 后端，并逐步扩展到代数函数。本文中的接口与新增文件名均为建议；代码现状以 2026-09-19 工作区为基准。

当前进度：已加入独立的 `exact_context::integrate_elementary` 诊断入口。
目前支持精确有理系数一元多项式 `Q[x]`，通过求导并逐项比较系数验证结果。
另外，对有理函数 `Q(x)` 会先做 Hermite 归约，将重复极点拆成有理函数的
导数与平方自由余项。归约恒等式经过有理式约分、规范化及精确比较；
余项若是分母对数导数的常数倍，可用局部 `ln` 积分并再次验证。
例如 `1/(x+1)^2`、`(x^2-1)/(x-1)` 和 `1/x` 已覆盖。
目前高次平方自由余项一般仍需精确对数根和表示；没有得到可验证原函数时，
返回 `unsupported`，并保留已验证的初等部分及余项。
对现有积分器构造的超越或简单代数候选，严格入口只接受由精确数、代数运算、
指数、对数、三角/双曲函数及其反函数组成的初等 DAG，并要求精确证明
`D(F)-f=0`。`Ei`、`erf`、`Si`、`Ci`、`partial_gamma` 和未求值积分不会被
误报为初等结果。当前回归覆盖单指数、嵌套指数、单/嵌套对数、指数对数混合、
有理指数表达式、三角平方以及 `1/sqrt(1-x^2)`；这是一条经过验证的桥接路径，
还不是具有完备分母界和无解证明的 Risch 塔算法。

基础 RDE 进度：已抽取 `Q[x]` 上的多项式方程 `y'+a*y=b` 求解器，使用无穷远
最高次项给出次数界、精确线性系统求系数，并代回多项式恒等式验证。单指数层
的多项式系数积分优先使用该求解器；无多项式解目前不会升级成“无有理解”或
“非初等”结论。原有有理系数超指数归约继续处理部分重复极点分母。

对 `f*exp(g)`（`f∈Q(x)`、`g∈Q[x]` 且 `g` 非常数）已接入严格判定。
有限极点阶给出完整分母界 `gcd(Q,Q')`，无穷远最高次项给出分子次数界；
在界内求解精确线性系统并代回验证。找到解时构造原函数，无解时返回
`proven_nonelementary`。`exp(x^2)`、`exp(-x^2)` 和 `exp(x)/x` 现在属于
已证明非初等。更高微分域中的一般 RDE 分母界仍未完成。

指数生成元 `t=exp(g(x))` 的有限 Laurent 多项式也已加入分派：表达式先按
整数幂 `t^m` 收集，系数限制为 `Q(x)`。零次项递归进入下层积分，非零次项
求解 `y'+m*g'*y=b_m`；有理 RDE 的分母界和无穷远次数界由现有求解器给出。
解出的各项组成初等部分，无解项保留为余项并标记 `proven_nonelementary`。
例如 `1/x + exp(x) + x*exp(x)^2` 可逐项处理。此路由不处理 `t` 的一般有理
函数。当 `g(x)=a*x+b` 且 `a` 为非零有理数时，另外支持完整有理函数子域
`Q(exp(g))`：以 `dt=a*t*dx` 换元后调用有理 Hermite/对数积分，再对换回来的
候选做原变量精确求导验证。因此 `1/(1+exp(x))`、`1/(1+2*exp(x))` 和
`exp(x)/(1+2*exp(x))` 可直接归约。非线性 `g` 的一般 `Q(exp(g))` 分母、
以及含其他超越下层系数的 RDE 仍未支持。

部分代数层现加入单一二次根式曲线的有理参数化：对 `y^2=x^2+b*x+c`
（`b,c∈Q` 且判别式非零），用 `t=y-x` 将 `x` 与 `y` 表为 `Q(t)` 中的有理
函数，乘入 `dx/dt` 后调用有理函数积分器，再以 `t=y-x` 代回。只在回代结果
通过原变量精确求导验证时接受。此算法处理的是该 genus 0 曲线上的有理微分；
它仍受当前有理函数因式分解/对数根和能力限制，不覆盖高次代数曲线、一般
非单项式二次根式或代数层非初等性证明。

primitive 层已实现子域 `x^m P(log(x))`（`m∈Z`、`P∈Q[t]`）。令
`t=log(x)`：当 `m!=-1` 时精确求解 `Q'+(m+1)Q=P`，当 `m=-1` 时利用
`dx/x=dt` 逐项积分。对于一般下层系数的 `P(t)`，现在从最高次幂向下解
`D(Q)=P` 的三角系数方程；每个系数调用下层严格积分器，若系数原函数重新
引入当前生成元则拒绝该路径。候选仍须经完整 DAG 求导和精确恒等式验证。
多个 primitive 生成元及完整参数化 RDE 仍在后续阶段。
同时实现了递归精确微分分支 `D(t)*P(t)`：选择表达式中最深的对数生成元，
在该生成元中逐项积分，并检查系数除以 `D(t)` 后与积分变量无关。该分支覆盖
`P(log(log(x)))/(x*log(x))` 以及同形的更深嵌套对数。
对 primitive 扩张 `t=log(x)` 还实现了纯极点归约。`r(x)/t^n` 先逐阶提取
`D(y/t^(n-1))`，最后对简单极点使用对数留数判定：初等原函数要求
`r(x)/D(t)` 为常数。因而 `1/(x*log(x))` 和 `1/(x*log(x)^2)` 可积，
而 `1/log(x)`、`1/(x^2*log(x))` 与 `1/log(x)^2` 会返回
`proven_nonelementary`；高阶情形同时保留已经验证的初等部分。该结论目前仅用于
分母为单个 `t` 幂且分子属于 `Q(x)` 的情形，尚未推广到 `Q(x)(t)` 的一般
平方自由分母与多个 primitive 生成元。
超过节点或次数预算返回 `resource_limit`；
除上面列出的多项式超指数、指数 Laurent 项和 primitive 极点范围外，尚不产生
`proven_nonelementary` 结论；
`conditions` 当前为空。
现有 `integrate` 的规则与特殊函数分派尚未迁移到严格入口。

## 1. 目标与交付边界

Risch 积分需要同时回答两个问题：能否构造初等原函数；如果不能，是否能证明不存在初等原函数。有限次数的模式匹配、待定系数搜索或分部积分不足以完成第二个问题。

分三层交付：

1. **R0：完备的有理函数后端。** 支持 `Q(x)`，以及明确声明、可有效运算的常数域上的有理函数；高次分母不再依赖根式求根。
2. **R1：受支持的纯超越初等扩张塔。** 支持由有理函数、指数、对数组成的正规微分域塔，包含递归 Risch 微分方程、参数化求解和初等可积性判定。每种塔必须通过常数域与生成元依赖检查；未通过检查的输入不属于判定范围。
3. **R2：代数扩张及混合扩张。** 实现代数函数域运算、局部归约、对数部分判定，以及代数与超越层相互递归的完整依赖。R2 是单独的大阶段，不能在实现几个根式积分规则后宣称完成。

首个实用版本以 R0 和 R1 的受限子集为目标。正式文档必须列出已完成的子算法与支持域，不笼统声称“完整 Risch”。

不纳入核心目标：定积分路径与奇点分析、数值积分、一般特殊函数积分、任意用户函数、含 `abs`/分段/取整的全局可积性判定。现有 `Ei`、`erf` 等规则仍由通用积分入口使用，但不参与初等可积性的证明。

## 3. 数学约定与正确性契约

### 3.1 输入域与常数问题

使用特征零微分域 `(K,D)`，`D=d/dx`，常数域记作 `C={a∈K | D(a)=0}`。基础层为 `K0=C(x)`。

第一版严格模式的 `C` 从 `Q` 开始，随后支持有效表示的代数数域。符号参数采用 `Q(a1,...,am)` 的泛型语义时，必须显式声明它们代数独立，并记录求解中使用的非零条件；不自动宣称结果覆盖所有参数特化。

“不含 x 的任意 DAG”只能视为候选常量，不能自动视为零判定、因式分解和代数关系均可判定的系数域。例如未指定关系的 `ln(2)`、`pi`、多个指数常数，需要受限域模型或返回 `unknown`。禁止借助浮点近似证明精确非零。

### 3.2 Liouville 形式与证明边界

初等可积性判定围绕以下形式展开：

```text
f = D(v) + Σ c_i * D(u_i)/u_i,     D(c_i)=0.
```

在相应定理假设下，`v`、`u_i` 位于适当的代数扩张中；纯超越算法须用相应下降结论将问题转为可计算的子问题。不能一开始就假定所有对象都属于输入域，也不能把“输入域内找不到原函数”当成“任何初等扩张中都不存在”。

实现时每个判定分支都附带所用定理、适用前提和完整的失败条件。理论路径可参考 Bronstein 的教程，但此文档给出的工程拆分和接口是本项目的设计选择。[Symbolic Integration Tutorial](https://www.math.kobe-u.ac.jp/HOME/taka/2007/knx/bronstein-tutorial-issac98.pdf)

### 3.3 统一归约不变量

所有阶段输出保持：

```text
f = D(elementary_part) + remainder
```

`elementary_part` 可以包含精确对数根和，但不能包含新的未求值积分或特殊函数。`remainder` 必须在同一已声明微分域中精确表示。

- 成功：`remainder=0`，且全部条件明确。
- 非初等：完整判定证明剩余部分没有初等原函数。
- 未完成：只保证分解恒等式，不对剩余部分作不存在性断言。

对和式不能简单合并各项的非初等标签：两个非初等余项可能相消。必须在共同塔中合并并规范化剩余项，然后重新判定。

### 3.4 实数、复数与分支

内部使用形式微分域语义，解析解释为避开奇点并固定分支后的局部恒等式。显示层按用户域选择 `log`、`ln(abs(...))` 或实数反三角形式，不能把局部正确表述为跨奇点的全局原函数。

- 在实数区间内，`1/x` 可显示为 `ln(abs(x))`；复数局部原函数使用 `log(x)`。
- `log(a*b)=log(a)+log(b)`、`log(exp(u))=u` 不能无条件用于全局分支转换。
- `sqrt(x^2)=x` 必须有适当符号条件。
- 若现有构造器已丢失输入分支信息，新入口只能保证收到的 DAG 的约定语义；要支持更强的全局语义，需要另行完善构造器和假设系统。

## 4. 结果类型与调用架构

### 4.1 新增诊断接口

以下为 C++17 风格的接口草案，不是可直接编译的声明：

```cpp
enum class risch_status {
    elementary,
    proven_nonelementary,
    unsupported,
    undecidable_constant,
    resource_limit,
    verification_failed
};

struct risch_result {
    risch_status status;
    exact_expr elementary_part;
    exact_expr remainder;
    condition_set conditions;
    certificate_handle certificate;
    risch_diagnostic diagnostic;
};

risch_result integrate_elementary(
    const exact_expr& f,
    const exact_expr& x,
    const risch_options& options);
```

每个有效输入都返回有效的 `elementary_part` 与 `remainder`，未取得进展时为 `0` 与原输入。非法变量、不同 context、损坏句柄沿用现有参数异常，不混入数学判定状态。

`proven_nonelementary` 表示 `remainder` 已证明非初等，从而原输入也无初等原函数；此时仍可返回已提取的初等部分。`unsupported` 等状态可以携带已经验证的部分结果。

条件不为空时，成功或否定结论仅在这些条件下成立。调用方如果不能呈现条件，就不能静默丢弃它们；应退回形式积分或已有的条件安全结果。

### 4.2 通用积分入口的分派

```text
检查输入与语义
  → 可精确验证的廉价初等规则
  → integrate_elementary / Risch 后端
  → 按策略尝试 Ei、erf、Si、Ci 等特殊函数
  → 初等部分 + 未求值剩余积分
```

迁移初期默认入口保持现有分派，新接口独立启用；回归稳定后再替换顺序。规则返回的候选只有通过精确验证才能进入诊断接口的 `elementary` 状态。特殊函数原函数可以是通用入口的成功结果，但其存在不改变初等积分接口的否定结论。

现有调用形态 `exact_context::integrate`、自由函数 `integrate`、`expr` 包装与 `dsolve` 保持兼容。不定积分接口仍省略任意积分常数，`dsolve` 继续负责生成自己的自由常数。

### 4.3 建议文件布局

```text

    rational_function.*  # 约分、求逆、规范形式

    rational_integrate.* # Hermite、RT/LRT
```

## 5. 精确代数基础层

### 5.1 系数域接口

系数域需提供 `add/sub/mul/inv/normalize/is_zero/equal`，并声明可用的因式分解、代数扩张和线性代数能力。`is_zero`、`equal` 使用 `yes/no/unknown`；求逆必须先确认非零或建立条件。

`Q` 中所有这些基本判定都是确定的。符号参数域中，规范分子为零决定泛型零；参数特化导致分母为零属于条件管理问题。任意表达式系数的未知零性必须沿调用链传播。

### 5.2 多项式和有理函数

- 第一版优先稠密一元多项式，保持与现有表示接近；根据真实基准决定是否增加稀疏表示。
- 统一零多项式、次数、首项和 monic 规范；零多项式不得按无符号次数参与循环。
- 实现欧几里得除法、精确整除、GCD、扩展 GCD、平方自由分解、resultant 与 subresultant PRS。
- 有理函数固定为互素分子/分母，分母首一；系数域未知时禁止伪造这种规范形。
- 明确区分形式偏导 `∂/∂t` 与微分域导子 `D`。
- 分式消元优先消除公因子，必要时采用 fraction-free 方法控制系数膨胀。

测试必须包括 `a=b*q+r`、Bezout 恒等式、平方自由因子重构、逆元恒等式，以及参数退化产生的条件。

## 6. R0：完整有理函数积分

### 6.1 Hermite 归约

输入 `f=A/B∈C(x)`，先约分与长除，再利用平方自由分解及扩展 GCD 消除重复极点，得到：

```text
A/B = D(U) + V/W
deg(V) < deg(W), gcd(V,W)=1, gcd(W,W')=1.
```

多项式部分的积分可以包含在 `U` 内。每次更新都记录重构恒等式，不要求先把 `B` 分解成一次、二次因子。平方自由分解不等于不可约因式分解。

验收包含高次重复分母、非真分式、输入先有公因子、常量分母及零输入。不得沿用固定次数试探作为数学上的终止依据；次数上限只属于资源预算。

### 6.2 对数部分与高次根表示

对平方自由余项 `V/W`，采用 Rothstein–Trager，并进一步实现 LRT 风格的子结式构造，避免展开所有分母根：

```text
R(z) = resultant_x(W, V - z*W')
```

`R` 的不同根给出留数；在相应常数扩张中，构造与 `gcd(W,V-c*W')` 对应的对数因子，恢复对数和。实现需处理内容因子、重根、多个极点具有相同留数，以及子结式在根处退化的情形。

新增内部对象：

- `AlgebraicConstant`：最小多项式、所属常数域、隔离区间或复隔离区域；不依赖近似排序识别根。
- `LogRootSum`：按平方自由定义多项式的不同根求有限和，带绑定变量、系数域和对数参数构造式。

根和是有限个初等项的精确表示，不是未求值积分。求导时使用定义关系约简，并通过迹/结式恒等式验证，避免全部根式展开。若在可约商环中运算，必须分解或采用明确的无除法算法；不能假定所有非零元素可逆。

DAG 接入需要同步 opcode、hash-consing、比较、打印、求导、替换、变量依赖、arena compact，以及可选数值求值；数值求值可以明确暂不支持，其他操作不能缺失。

低次根优先输出已有根式或 `atan` 形式。`1/(x^5-x+1)` 之类有理函数必须可以返回精确初等结果，不得因没有五次根式公式而返回非初等。

**R0 完成标准：** 在已声明有效常数域、根表示可用且预算充足时，任意有理函数都返回可验证的初等原函数。

## 7. 微分域塔构造与规范化

### 7.1 层结构

```text
K0 = C(x), D(x)=1
Ki = K(i-1)(ti)

primitive:   D(ti)=ai，ai 属于下层
             对 log(ui)，ai=D(ui)/ui
exponential: D(ti)=ai*ti，ai 属于下层
             对 exp(ui)，ai=D(ui)
algebraic:   Pi(ti)=0，后期支持
```

先实现由对数引入的 primitive 层，不将任意形式积分直接作为新生成元。每层保存类型、下层 ID、导数数据、原 DAG 映射、条件和准入证据。

元素用递归的一元有理函数表示。对多项式有：

```text
D(Σ a_j*t^j) = Σ D(a_j)*t^j + Σ j*a_j*t^(j-1)*D(t).
```

因此 `log(x)*exp(x)` 中的 `log(x)` 系数不能按常数处理。

### 7.2 建塔步骤

1. 检查精确数值、积分变量和语义模式。
2. 遍历 DAG，收集依赖变量的指数、对数及代数节点。
3. 按依赖拓扑排序，同层候选用稳定规范序排序。
4. 将 `log2`、`log10` 在相应常数域可处理时转为自然对数；`e^u` 统一为 `exp(u)`。
5. 检查候选生成元是否可由已有塔表示，复用同一生成元或转为已有元素。
6. 对无法证明是合法新超越生成元的情形返回明确的 unsupported/unknown，不盲目新增独立变量。
7. 检查每层导子闭合性、关系一致性和不引入新常数的前提。
8. 验证输入 DAG 到塔的转换和反向输出保持约定语义。

典型关系包括 `exp(2*x)=exp(x)^2`、`exp(-x)=1/exp(x)`；`exp(x/2)` 与 `exp(x)` 应统一到较细的生成元。`log(x^2)` 与 `2*log(x)` 的关系涉及分支常数，应按语义策略处理，不能直接当成两个独立超越元。

一般指数乘法关系、对数关系和常数扩张检查需要递归求解能力。为避免启动依赖循环，第一版只接受具有可验证构造证据的塔；其余返回未支持。后续使用下层的对数导数判定、整数关系和参数化求解扩大准入范围。

## 8. R1：超越层归约与递归积分

### 8.1 normal / special 分母

在 `K[t]` 中按完整导子 `D` 区分因子：normal 因子满足 `gcd(p,D(p))=1`；special 因子满足 `p | D(p)`。一般平方自由分母需要按相应算法拆成这些部分，不能把普通 `∂p/∂t` 的平方自由分解直接当成微分分解。

- normal 的重复极点进入微分 Hermite 归约。
- simple normal 部分进入微分留数与对数部分判定。
- special 部分进入对应扩张类型的专门算法。
- 多项式部分进入次数归约和低层 RDE。

例如指数层中 `t` 是 special，负幂 `t^-m` 是合法 Laurent 项；不能因为没有普通有理函数式的处理分支而把它判为非初等。

每个过程输出 `D(g)+r` 的证据。微分留数判定需要检查留数是否为常数，并在必要的代数常数扩张中构造对数项；直接套用 R0 的 `W'` 公式并不足够。

### 8.2 primitive / 对数层

当 `D(t)=a∈K` 时，先归约有理部分，再对 `Σ b_j*t^j` 从最高次数递归消去。

若候选为 `Σ y_j*t^j`，系数满足：

```text
D(y_j) + (j+1)*a*y_(j+1) = b_j.
```

下层积分得到的自由常数会影响下一层系数，必须保留为参数并统一求解。不能逐项取一个任意原函数、丢掉积分常数后继续，也不能假定输出次数必定不超过输入次数：次数上界必须由对应算法给出。

此阶段依赖参数化 RDE、下层初等积分与对数导数关系求解。建议先完成单层 `log(x)`，再支持 `log(log(x))`、有理函数的对数和指数/对数混合塔。

### 8.3 exponential 层

当 `D(t)=a*t` 时，对 Laurent 多项式项 `b_m*t^m`，候选 `y_m*t^m` 导出：

```text
D(y_m) + m*a*y_m = b_m.
```

`m=0` 递归到下层积分，正负 `m` 都进入下层 RDE。非 Laurent 的一般有理部分先完成 normal/special 归约和留数判定。

先覆盖 `C(x,exp(g(x)))`，再逐步覆盖 `C(x,log(x),exp(x))` 与嵌套指数。单个 RDE 无解只有在完整归约定理说明该方程是必要条件时，才可以升级为积分非初等结论。

## 9. Risch 微分方程求解器

### 9.1 输入、输出与算法顺序

核心方程为：

```text
D(y) + a*y = b,     a,b∈K，寻找 y∈K.
```

内部状态为 `solved / no_solution / unsupported / unknown / resource_limit`。`no_solution` 必须有完整界与不可解证据；固定试探次数失败只能返回未完成。

实现顺序：

1. 规范化 `a,b`，单独处理 `a=0`、`b=0` 与齐次解空间。
2. 用 normal 极点赋值推导分母界，记录每个不可约因子或平方自由块的极点阶约束。
3. 对 special 因子推导额外界；普通极点公式不能覆盖它们。
4. 令 `y=z/q`，清分母得到多项式微分方程。
5. 分析无穷远最高次项，推导次数界；处理首项抵消、整数共振和需要下层方程判定的例外。
6. 在已证明的界内求解多项式方程，系数问题递归到下层。
7. 代回 `D(y)+a*y-b` 精确归零。

基础域 `C(x)` 中可将有限未知量交给精确线性代数。在更高层，系数属于微分域，不能把它们当成常数直接用普通 Gaussian 消元替代递归微分方程求解。

### 9.2 参数化版本

需要求解：

```text
D(y) + a*y = Σ c_i*b_i,     c_i∈C.
```

输出是 `(y,c_1,...,c_n)` 解空间的一组常数域基，而不是单个特殊解。应覆盖齐次解、零右端、自由参数和退化秩。

对数关系判定所需的整数系数条件也须单独处理；常数域上的线性空间求解不能自动代替整数关系求解。未实现相关关系算法时限制塔准入，不能假装生成元独立。

### 9.3 初期 RDE 验收

| 方程 | 预期 |
| --- | --- |
| `y'+y=x`，`y∈Q(x)` | `y=x-1` |
| `y'+y=x/(x+1)^2` | `y=1/(x+1)` |
| `y'+2*x*y=2*x` | `y=1` |
| `y'+2*x*y=1` | 完整算法证明无有理解 |
| `y'+a*y=1` | 泛型 `a!=0` 时 `1/a`；`a=0` 时 `x` |
| 人为降低分母/次数预算 | `resource_limit`，禁止 `no_solution` |

可参考 SymPy 的 RDE 实现梳理分母归约、次数界与多项式求解的接口分工，但本项目需针对自己的系数域和证据结构重新实现。[SymPy rde.py](https://github.com/sympy/sympy/blob/master/sympy/integrals/rde.py)

## 10. 三角、双曲与一般幂

待复代数常数和指数塔稳定后，加入规范转换：

```text
sin(u)  = (exp(i*u)-exp(-i*u))/(2*i)
cos(u)  = (exp(i*u)+exp(-i*u))/2
sinh(u) = (exp(u)-exp(-u))/2
cosh(u) = (exp(u)+exp(-u))/2
```

同一 `u` 的正负指数必须共用生成元。`tan`、`tanh` 转为这些生成元的有理式；整数倍频率先做关系消除，非整数关系需要常数域支持。

反三角及反双曲函数可按固定分支转换为对数/根式，但会引入代数函数扩张，因此不能在 R2 之前承诺一般支持。现有直接规则继续保留。

`u^v` 的策略：整数幂直接处理；有理指数优先进入代数扩张；一般指数只能在明确局部分支下转换为 `exp(v*log(u))`。常数底数的 `a^x` 需要处理 `a=0`、`a=1` 和 `log(a)` 所属常数域，不能无条件除以 `log(a)`。

实数结果美化放在证明完成之后，只有能验证的共轭配对才改写为实对数或反三角式；美化失败保留正确的复形式。

## 11. R2：代数函数与混合扩张

必须区分：R0 中的“代数常数根”满足 `D(alpha)=0`；代数函数根 `alpha(x)` 通常导数非零。前者完成不代表后者已实现。

### 11.1 有效代数函数域

对不可约、可分的关系 `P(x,alpha)=0`，在已有域上实现模最小多项式约简、逆元、范数、迹及扩张兼容性。导子由关系导出：

```text
D(alpha) = -D_coeff(P)(alpha) / (∂P/∂alpha)(alpha).
```

`D_coeff` 只作用于系数。必须先确认所用关系定义的是域；可约多项式应分支、分解或采用正确的商代数算法。

### 11.2 逐级实现路线

1. 先将现有二次根式规则纳入统一域内验证，覆盖 `sqrt(P(x))` 的简单情况。
2. 对可参数化的 genus 0 曲线实施有证明的有理参数替换，并验证逆向代入。
3. 实现一般代数函数域的整基或经过证明适用的惰性整基算法、有限点和无穷远局部展开/赋值。
4. 在分歧点也正确执行代数 Hermite 归约，提取精确微分部分。
5. 计算留数与候选对数微分；实现所需的除子、主除子判定和相关有限维计算。
6. 在明确常数域条件下完成剩余第一类/第二类微分与对数部分的初等性判定，不能仅凭“剩余非零”下结论。
7. 实现代数层上的 RDE 与参数化子问题，再与外层对数、指数塔组合。

第 5—7 步是独立研究与实现里程碑，实施前补充具体算法出处、终止条件及可计算性前提。如果相关子算法尚不可用，API 必须返回 unsupported。

区分用例：`1/sqrt(1-x^2)` 有初等原函数；`1/sqrt(x^3-x)` 在相应非奇异代数曲线上属于非初等情形。第二个用例不能因为现有二次根式规则失效就被标记为已证明非初等。

## 12. 验证、证据与错误处理

### 12.1 正向验证

采用两层检查：

1. **域内检查：** 在输入塔及结果引入的合法扩张中规范化 `D(F)+r-f`，证明为零。
2. **DAG 检查：** 将结果转回表达式后调用既有求导，并重新导入域内验证，捕获构造、符号或转换错误。

通用 `simplify(diff(F,x)-f)` 可作快速检查，但未化简为零不是反证。数值采样仅用于发现错误，不作为证明。针对复分支或特殊函数的采样避开极点与分支切割，并明确其辅助性质。

### 12.2 否定证据

建议证据包括：

- 塔和常数域标识、生成元准入证明及全部假设。
- Hermite/多项式归约的重构恒等式。
- 阻碍初等性的规范剩余项及所用判据。
- RDE 分母界、次数界、例外分支检查，以及最终线性/递归系统不可解证据。
- 算法版本、子问题引用及预算完成标志。

验证器重放代数恒等式与边界推导，不依赖搜索器的“失败”布尔值。首版可先实现内部结构化证据，不必立即设计公开序列化格式；在否定证据链完成前，统一返回未完成状态。

### 12.3 资源与诊断

统一预算包括塔高、多项式次数、总项数、系数位数、矩阵规模、PRS 中间项规模、DAG 节点增量和工作量计数。时间限制可补充，但测试优先使用确定性工作量预算。

诊断应指出失败位置，如“第 3 层常数关系未知”“RDE special 分母分支未实现”“resultant 超过项数预算”。任何预算耗尽都不得转为非初等结论。

缓存键包含 arena 身份、变量、域塔、假设与语义模式；arena compact 后不得继续用裸 node ID 命中旧缓存。跨会话缓存须使用稳定内容标识。

递归求导和构造可能使 arena 存储重分配，不能跨新增节点操作保存易失效的 child 指针或节点引用。新模块应保持现有代码中复制节点和操作数的安全习惯。

## 13. 测试计划

### 13.1 确定性验收样例

以下 `log` 表示内部局部对数；对应 CLI 语法可使用 `ln`。条件按实数/复数模式单独检查，不要求打印字符串完全一致。

| 输入 | 核心预期 | 阶段 |
| --- | --- | --- |
| `0`、`7`、`x^7` | `0`、`7*x`、`x^8/8` | R0 |
| `1/x`、`1/(1+x^2)` | 初等，按模式输出对数或 `atan` | R0 |
| `1/(x^2+1)^2` | `x/(2*(x^2+1))+atan(x)/2` | R0 |
| `1/(x^5-x+1)` | 初等，可用精确对数根和 | R0 |
| `D((x+1)/(x^3+2))` | 原函数可恢复到常数差 | R0 |
| `exp(x)`、`x*exp(x)` | `exp(x)`、`(x-1)*exp(x)` | R1 指数 |
| `x*exp(x)/(x+1)^2` | `exp(x)/(x+1)` | R1 RDE |
| `2*x*exp(x^2)` | `exp(x^2)` | R1 RDE |
| `exp(x^2)`、`exp(-x^2)` | 证明非初等；通用入口可给 `erfi`/`erf` | R1 判定 |
| `exp(x)/x` | 证明非初等；通用入口可给 `Ei` | R1 判定 |
| `log(x)`、`log(x)^2` | 初等，需 primitive 多项式归约 | R1 对数 |

| `exp(x)*exp(exp(x))` | `exp(exp(x))` | R1 嵌套 |
| `exp(x)*(log(x)+1/x)` | `exp(x)*log(x)` | R1 混合 |

| `x*exp(x^2+log(x))` | 在约定局部语义下与 `x^2*exp(x^2)` 等价 | 关系归一化 |
| `sin(x)^2` | `x/2-sin(2*x)/4` | 三角转换 |

| `1/sqrt(x^3-x)` | 完成代数判定后证明非初等 | R2 |

“关系归一化”样例主要检查导入等价性；不把它作为简单积分成功用例。

### 13.2 失败语义与退化测试

- 近似系数进入严格模式：明确拒绝或返回 unsupported，不自动有理化。
- 未声明的常数关系：unknown/undecidable_constant，不作为非零主元。
- `exp(a*x)`、`1/(a*x+b)`：覆盖 `a=0` 与泛型非零条件。
- `a^x`：覆盖合法非零底数、`a=1` 以及未定义情形。
- 随机重排加法/乘法和改变符号名：状态与数学结果不变。
- 输入具有相关指数生成元：避免错误的独立变量建塔。
- 显式注入低预算：只能得到 resource_limit 或已验证的部分结果。
- 两个非初等余项相消、以及初等项加非初等余项：检查合并语义。
- `abs(x)`、未知函数、未实现代数层：不得给出无依据的非初等结论。
- 跨 context 句柄、arena 压缩、深层 DAG：覆盖有效性和缓存生命周期。

### 13.3 性质测试、对照与性能

从受支持塔随机生成 `F`，取 `f=D(F)` 后积分，检查结果的导数等于 `f`，不要求恢复同一个字符串。生成器要控制塔合法性与资源，不生成未经证明的独立关系。

对 RDE 随机选择 `a,y` 并生成 `b=D(y)+a*y`，检查能找回某个解；另建立人工证明的无解语料，避免只测正例。

可使用固定版本 SymPy 作为离线对照，记录版本与输入。其 Risch 接口区分证明非初等与尚未实现，但实现范围有限，因此对照工具的失败不能用作本项目的否定证明。[SymPy 积分文档](https://docs.sympy.org/latest/modules/integrals/integrals.html)

性能语料按有理分母次数/重数、塔高、项数、参数数量分类，记录耗时、峰值节点数、系数位数、GCD/PRS 次数及缓存命中。先建立基线，再选择真实瓶颈优化；CI 使用确定性规模和工作量上限，避免仅用墙钟时间判定。

## 14. 分阶段实施与验收门槛

| 阶段 | 主要交付 | 依赖 | 可以合并的验收条件 |
| --- | --- | --- | --- |
| M0：基线与语义 | 整理既有积分/ODE 回归；状态、条件、预算定义；支持域矩阵 | 无 | 旧接口行为保持；未实现与非初等已区分 |
| M1：域内代数 | 精确系数域、多项式、有理函数、三态零判定 | M0 | 全部代数不变量和参数条件测试通过 |
| M2：有理归约 | Hermite、PRS、resultant、RT/LRT | M1 | 重复极点与平方自由余项均精确重构 |
| M3：精确输出 | 代数常数、LogRootSum、DAG 配套 | M2 | 高次有理函数不依赖根式；R0 验收通过 |
| M4：塔基础 | primitive/exponential 表示、导子、受限建塔 | M1 | 转换往返、关系消除、常数检查可验证 |
| M5：基础 RDE | `C(x)` 分母界、次数界、解/无解证据 | M1、M4 的接口 | 有理解、共振、无解与预算测试全部通过 |
| M6：单层超越 | normal/special 归约、单指数/单对数层 | M3–M5 | 指定单层用例可求解或给出有效否定证据 |
| M7：递归超越 | 参数化 RDE、关系判定、混合/嵌套塔 | M6 | 已声明支持的正规塔完成 R1 验收 |
| M8：通用入口 | 三角转换、条件显示、策略分派、CLI/expr/ODE 接入 | M7 | 全部既有回归通过；新旧接口条件不丢失 |
| M9：代数函数 | 有效代数函数域、局部归约、对数判定 | M3、M7 | 代数正例/反例均有证据；范围单独公布 |
| M10：混合闭合 | 代数层 RDE 与超越层交互 | M9 | R2 定义的全部前提与子算法闭合 |

M3 与 M4/M5 在接口稳定后可分别推进，但每个阶段都应独立可回归。M9/M10 不能仅以工期结束作为完成依据；先提交更具体的算法设计评审，再进入实现。

建议按以下小步 PR 开始：

1. 引入结果状态与严格入口，尚未覆盖的输入全部明确返回 unsupported。
2. 抽取现有精确一元多项式工具并补齐 GCD/Bezout 不变量。
3. 实现不依赖低次因式分解的有理 Hermite 归约。
4. 实现代数常数与有限对数根和的最小完整生命周期。
5. 接入 RT/LRT，完成 R0；随后启动微分域塔和通用 RDE。

不要第一步整体改写 `exact_context::integrate`，也不要先扩充大量匹配规则来代替基础层。每个 PR 都应说明新增支持域、未知分支、验证方式和资源行为。

## 15. 主要风险与最终完成标准

| 风险 | 应对 |
| --- | --- |
| 任意表达式常数的零判定不完备 | 明确有效常数域；unknown 全链路传播 |
| 生成元存在隐含关系 | 正规塔准入证据；受限输入先行 |
| 错把搜索失败当无解 | 只有完整界和证据才能返回否定状态 |
| 高次根式输出爆炸 | 精确根和、迹与子结式表示 |
| 参数除零、分支条件丢失 | 条件是结果的一部分；不支持呈现则保留形式积分 |
| RDE 系数增长与递归循环 | 规范表示、缓存、递减度量和显式预算 |
| 通用化简影响证明可靠性 | 以域内规范形和可重放证据为准 |
| DAG 新节点仅支持打印 | 将求导、替换、compact、依赖分析纳入同一验收 |
| 代数部分工作量低估 | 独立里程碑，公开尚未完成的子算法 |

每个发布层级都必须满足：

- 支持域和前提被明确描述，并可由入口检查。
- 成功结果通过精确求导验证；部分结果满足分解恒等式。
- 非初等结论有可重放证据，资源失败和未实现绝不伪装成证明。
- 参数条件与局部分支语义能够传递到调用者。
- 现有积分、表达式、计算器及 `dsolve` 回归无退化。
- 新源文件进入全部相关构建入口，性能与资源行为具有可重复基线。

只有 M9/M10 所需的代数与混合子算法也完成，并且所有常数域与表示前提都得到满足后，才考虑使用“完整 Risch 实现”这一表述；任何时候都应同时附上精确适用范围。
