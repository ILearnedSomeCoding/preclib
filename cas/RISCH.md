# Risch 符号积分实现计划

本文是面向当前 prec-cpp CAS 的开发设计，不表示下列能力已经实现。目标是在现有积分器之上建立一个具有明确适用域、精确验证和失败语义的 Risch 后端，并逐步扩展到代数函数。本文中的接口与新增文件名均为建议；代码现状以 2026-09-19 工作区为基准。

当前进度：已加入独立的 `exact_context::integrate_elementary` 诊断入口。
`risch_result.conditions` 中每个表达式约定为非零条件。严格入口现检查
已找到的原函数中变量无关的倒数底数；无法证明非零时保留条件，而不是
把 `exp(a*x)/a` 或 `ln(a*x+b)/a` 宣称为无条件结果。顶层加法合并这些
条件，普通积分调用严格入口的代数桥接不会丢弃它们。其它尚未覆盖的
参数分支与非初等证明仍需独立条件分析，不能据此宣称参数域完备。
目前支持精确有理系数一元多项式 `Q[x]`，通过求导并逐项比较系数验证结果。
另外，对有理函数 `Q(x)` 会先做 Hermite 归约，将重复极点拆成有理函数的
导数与平方自由余项。归约恒等式经过有理式约分、规范化及精确比较；
余项若是分母对数导数的常数倍，可用局部 `ln` 积分并再次验证。
例如 `1/(x+1)^2`、`(x^2-1)/(x-1)` 和 `1/x` 已覆盖。
高次平方自由余项现可由精确 `LogRootSum(P,W,x)` 节点表示，不需要展开高次
代数根；节点求导严格化为 `P/W`。因此 `1/(x^5-x+1)` 已能返回精确初等原函数。
高次重复极点通过精确 Hermite 线性系统归约；系统规模受严格入口的有理次数预算
限制。测试已覆盖 13 次分母的平方。预算内若精确重构不成立会返回
`verification_failed`；超出输入次数/节点预算则返回 `resource_limit`。
有理式幂指数不再另受 32 次的解析器硬限制：严格入口按 `maximum_degree`
检查幂与结果次数，并在多项式快速幂前拒绝超预算展开。调用者可提高默认 64 次
的次数预算（受输入节点预算约束）；Hermite 稠密系统另受 `maximum_matrix_entries`
限制，默认最多 65536 个矩阵项，超限明确返回 `resource_limit`。回归覆盖 80 次线性
极点以及矩阵预算耗尽。
严格入口现在也将提高后的次数预算传给有理原函数和 `LogRootSum`
构造；`1/(x^80+1)` 在 96 次预算下能返回经求导验证的初等结果，
默认 64 次预算则明确返回 `resource_limit`。公开的 `log_root_sum`
仍默认 64 次，调用者可显式传入更高的次数预算。纯多项式分支的
输入解析与导数验证也使用同一预算，回归包含 `x^80`。
普通 `integrate()` 也会尝试同一 Hermite 归约：在最高 64 次的有界路径内，
生成有理导数项与平方自由 `LogRootSum`，并对候选求导、规范化后与输入有理式
进行精确比较；验证不通过则保留原来的未求值积分，不会返回未经验证的候选。
对现有积分器构造的超越或简单代数候选，严格入口只接受由精确数、代数运算、
指数、对数、三角/双曲函数及其反函数组成的初等 DAG，并要求精确证明
`D(F)-f=0`。R0 有理函数路径另接受经多项式检查的 `LogRootSum` 节点，其导数按
部分分式恒等式精确还原输入。`Ei`、`erf`、`Si`、`Ci`、`partial_gamma` 和未求值
积分不会被误报为初等结果。当前回归覆盖单指数、嵌套指数、单/嵌套对数、指数对数混合、
有理指数表达式、三角平方以及 `1/sqrt(1-x^2)`；这是一条经过验证的桥接路径，
还不是具有完备分母界和无解证明的 Risch 塔算法。
严格入口会递归拆分顶层加法，为每项累计已验证原函数和剩余项，并精确验证
`D(elementary_part)+remainder=input` 后再返回。因此不同指数生成元的可积项可相加，
也能为混合表达式保留可积部分，例如 `1/x+exp(x)/x`。恰有一个非零余项且
该项已被证明非初等时可传播 `proven_nonelementary`；多个余项的和可能相消，
须先合并并重新证明。当前对一个平方根或两个独立平方根的全纯余项有这种
共同域证明，其余多余项情况保留为 `unsupported`。

基础 RDE 进度：已抽取 `Q[x]` 上的多项式方程 `y'+a*y=b` 求解器，使用无穷远
最高次项给出次数界、精确线性系统求系数，并代回多项式恒等式验证。单指数层
的多项式系数积分优先使用该求解器；无多项式解目前不会升级成“无有理解”或
“非初等”结论。原有有理系数超指数归约继续处理部分重复极点分母。

对 `f*exp(g)`（`f∈Q(x)`、`g∈Q[x]` 且 `g` 非常数）已接入严格判定。
有限极点阶给出完整分母界 `gcd(Q,Q')`，无穷远最高次项给出分子次数界；
在界内求解精确线性系统并代回验证。找到解时构造原函数，无解时返回
`proven_nonelementary`。`exp(x^2)`、`exp(-x^2)` 和 `exp(x)/x` 现在属于
已证明非初等。乘积中的指数因子会先按 `exp(a)*exp(b)=exp(a+b)` 合并，再对
合并后的多项式指数尝试同一 RDE；例如 `(1+2*x)*exp(x)*exp(x^2)` 可积为
`exp(x+x^2)`。指数 Laurent 项还会识别彼此为有理数倍的多项式指数，取比例分母
的公倍数构造共同基指数 `g`，再将各项精确归一化为 `exp(g)^k`；例如
`2*exp(2*x)+exp(x)` 以及 `2*exp(2*x)+3*exp(3*x)` 可进入同一指数 Laurent RDE。
幂指数受 `int64_t` 范围约束。相差有理常数的有理函数指数参数现通过
导数比例及常数差的精确比较归一化，偏移量留作 `exp(c)` 常数因子。
对于归一化后系数在积分变量上为精确常数、分母为单项式的单指数
有理式，可逐项积分并通过有理恒等式验证；符号系数若需取倒数，
结果保留相应非零条件。例如
`exp(x+1)/(exp(x)+exp(x+1))` 和 `1/(exp(x)+exp(x+1))`。
指数参数为有理仿射函数时，也可对分母 `d0+d1*exp(g)`、任意预算内
多项式分子、`d0,d1` 为精确符号常数系数的式子积分；先在
`C[exp(g)]` 做长除，再分别处理多项式项与 normal 一次极点，
结果用有界的形式有理式恒等检查验证。不能证明符号系数非零时，
结果带有相应非零条件；系数为零的特化必须单独重新积分。
`1/(1+exp(x)+exp(x+1))` 和 `1/(a+exp(x))` 属于这一范围。一般常数关系、更高次
符号常数系数分母以及更高微分域中的 RDE 分母界仍未完成。
对单个仿射 normal 因子的重复幂 `P(exp(g))/(d0+d1*exp(g))^m`，
`P` 为预算内精确常数系数多项式、`m>=2` 且 `g` 为有理仿射函数时，
逐次合成除法得到多项式与各阶极点，再合并有理项和对数项。
最终以精确导数恒等式验算；形式判零会消去相抵的对数系数，
只对结果中真正出现的符号倒数保留非零条件。
预算内总重数至多八的互异仿射一次 normal 因子及精确常数系数
多项式分子，现可做多项式长除。每个根处的截断幂级数给出
`1/L_i^k` 的主部系数，结果由单因子重复极点递推公式构造。
输出前逐系数验证 `P=Q*prod(L_i^m_i)+sum(C_i,k*prod(L_j^m_j)/L_i^k)`，
避免对整个多对数候选做组合爆炸的展开。结果保留常数项、
斜率项与互异行列式的必要非零条件。比例相同但表达式不同的
一次因子先按根归并并调整分子，再用同一恒等式验算。
这尚未处理不可分解的高次 normal 因子或一般下层系数域。
精确数值系数的高次 normal 分母另可在有理仿射指数 `t=exp(s*x+c)`
下换元为 `Q(t)` 上的有理积分；输出前在临时变量中逐项验证导数恒等式，
再代回指数。证书局部去掉实对数的 `abs`，并约化精确数值根号的偶数幂；
实际输出保留原来的实对数形式。已覆盖二次与三次分母。
对精确符号常数系数二次分母 `a+b*t+c*t^2`，当 `a,c,Δ=b^2-4ac`
非零时，用两根的留数和多项式长除积分，在
`Q(参数)[sqrt(Δ)]` 中逐系数验证分式恒等式。若能精确证明
`Δ=0` 且 `a,c` 非零，则改用一个重复根的简单极点与二阶极点，
同样逐系数验证。无法证明退化关系的参数特化仍须重新积分；
三次及以上符号常数分母仍需一般常数域代数扩张算法。
若能精确证明 `a=0` 且 `b,c` 非零，则换元后的 `t=0` 是二阶
special 极点，按一、二阶系数与另一简单根分解，并验证重构恒等式。
相关仿射指数之间的有理常数偏移（如 `exp(2*x+1)`）可作为精确
常数系数保留，再进入上述二次证书。
多个有理倍相关的仿射指数也复用同一证书，先归一到共同的临时变量，
因此 `1/(1+exp(x)+exp(2*x))`、`1/(1+exp(x)+exp(-x))`
以及 `1/(1+exp(x/2)+exp(x))` 可在单层递归预算内直接完成。

参数化 RDE 基础现新增 `Q[x]` 上的完整多项式解空间：
`y'+a*y=sum(c_i*b_i)`，`a,b_i` 为有理系数多项式。
由最高次项给出统一次数界，将 `y` 的系数和所有 `c_i` 一起放入
齐次精确线性系统，输出零空间基，并逐个验证微分方程。
`a=0` 保留常数齐次解；相关或零右端保留参数关系，不强行要求满秩。
现有单右端多项式 RDE 已调用该核心。它只证明多项式解空间，不是一般
有理解或高层微分域的参数化 RDE；完整递归塔的自由常数传播仍未实现。
内部 API 有矩阵项预算，超限返回 `resource_limit` 而非无解。
专用测试见 `cas/test/test_risch_parametric.cpp`，直接包含实现，因此编译
时应排除单独链接 `cas/src/prec_cas.cpp`；覆盖齐次解、相关右端、无解、
空右端、构造解回归和预算耗尽。

基础域参数化 RDE 现另支持 `a in Q[x]`、`b_i in Q(x)`。
统一取右端分母的最小公倍多项式 `L`，用 `h=gcd(L,L')` 界定有限极点，
令 `y=z/h`，按无穷远次数界确定 `z` 的次数，并求解所有 `(z,c_i)` 的
齐次线性系统。每个解空间基经清分母恒等式验证，再规范化为 `y` 的分子分母。
`a=0` 保留常数齐次解；多个右端相消时保留相应参数方向。
原有单右端有理 RDE 已通过该核心提取 `c_1!=0` 的解；没有该方向才返回
原有无有理解状态。内部预算耗尽单独返回 `resource_limit`。
此范围不包含有极点的 `a`，其共振和 special 分母界仍待实现。

有极点的 `a` 新增有理规范变换分支：先分离多项式部分 `a0`，对 proper
部分尝试构造整数系数对数原函数，从而得到有理函数 `u`，并精确验证
`a-a0=u'/u`。令 `z=u*y`，将参数化方程转换为
`z'+a0*z=sum(c_i*u*b_i)`，求得解空间后再除以 `u`。
该变换可保留极点处的齐次解，涵盖检测到的整数对数留数，而不是把
多项式 `a` 的分母界直接套到原方程。输入及变换次数受预算约束。
它已接入超指数有理积分，指数参数不必再限于多项式，只要求导数能通过
此精确变换处理。回归覆盖正负整数留数、二次因子、齐次解、构造特解，
并经严格积分入口验证。该规范变换本身不能处理非整数留数和高阶极点；
下述直接分支补充部分范围。仍未覆盖的输入返回 `unsupported`，
不把这类失败当成无有理解或非初等证明。

基础域 RDE 新增单个简单极点的直接分支：
`a=a0+r/(x-c)`，其中 `a0 in Q[x]`、`r,c in Q`。
正整数 `r` 允许齐次解在 `c` 处出现 `r` 阶极点，因此共同分母包含
该共振阶数；其它极点沿用右端极点阶减一的界。
若 `a0=0` 且 `-r` 是非负整数，无穷远次数界还包含共振次数 `-r`。
非整数留数不产生这些共振，但同样进入精确参数化线性系统。
该分支不依赖对数原函数或有理规范因子，且已接入规范分派与超指数积分。
回归覆盖平移极点、正负整数齐次解和正负半整数留数的构造有理解。
多个极点及高阶极点由下述扩展处理；不宣称完成一般基础域 RDE。

上述直接分支现扩展到平方自由分母可完整分解为有理线性因子的情形。
分解后先验证因子乘积等于规范分母且不存在重复极点，才逐个计算
`r_c=proper_numerator(c)/denominator'(c)`。每个正整数留数独立调整有限
分母界；无穷远的共振次数使用所有留数之和，而不是只看一个极点。
参数化解仍经完整清分母方程验证。分解未完成不是不可约或无解证明，
会退回已有规范变换，仍不能处理的输入返回 `unsupported`。
回归包含整数与半整数留数混合、多个极点相互作用和两端共振齐次解。
直接分支现也支持上述有理线性因子的重复幂，即高阶极点。
因子列表保留重数，先精确重构规范分母；二阶及以上极点处
`a*y` 的最高极点阶高于 `y'`，不存在简单极点的整数留数抵消，
因此右端共同分母导出的普通极点界仍为安全上界。仅对重数为一的
极点增加共振界，避免在重复根处除以零。无穷远的共振使用 proper
部分的 `1/x` 系数（由最高次系数精确读取），包含重复极点的贡献。
回归覆盖二阶、三阶极点、混合共振、无非零有理齐次解、
不完整因子列表拒绝以及 `exp(-1/x)` 的严格积分验证。
不可约高次因子的非整数留数及一般递归塔 RDE 仍在后续阶段。

高阶极点分支进一步覆盖不可约多项式因子，不必展开其代数根。
当 `rad(ad)=ad/gcd(ad,ad')` 整除 `gcd(ad,ad')` 时，所有有限极点
的阶数至少为二，可直接使用普通极点界，不依赖完整因式分解。
混合分母若分解成功，则精确检查每个因子平方自由、不同因子互素、
因子乘积及重数；允许高次因子的重复幂，但仍要求简单极点因子为线性。
候选始终经清分母恒等式验证。测试包含 `(x^2+1)^2`、不同重复阶数
的混合分母、简单极点与不可约重复因子的组合，以及
`exp(1/(x^2+1))` 的严格积分。不可约简单极点的通用留数判定尚未完成。

不可约简单极点现新增常数留数的直接判定：对平方自由因子 `p`，
检查 `proper_numerator mod p = r*(ad' mod p)` 是否精确成立。
成立时全部根的留数都是同一个有理数 `r`，可沿用整数共振界；
无需构造代数根或对数规范因子。平方自由分母也可先作为一个整体
检查常数留数，避免不必要的分解。测试覆盖二次因子上的正负整数
齐次解、正负半整数的构造特解及无非零有理齐次解。
余式不成比例时保留 `unsupported`，不会据此宣称无有理解；
各代数根留数不同的通用判定仍需后续算法。

上述非恒定留数限制现由精确商环分支补充。对每个简单极点的
平方自由因子 `p`，在 `Q[x]/(p)` 中解出 `r=proper_numerator/ad'`，
并验证乘回余式恒等式。构造乘以 `r` 的矩阵，用
Faddeev-LeVerrier 算法求特征多项式，最后检查 Cayley-Hamilton
余矩阵为零。特征多项式的 Cauchy 根界限制可能的正整数留数；
在该界内对每个整数 `k` 计算 `gcd(p,proper_numerator-k*ad')`，
精确提取产生 `k` 阶共振的因子。代数非整数留数不需要求值或展开。
平方自由分层使用 Yun 的 GCD/精确除法步骤，因而基础域分派不再
要求先完成有理因式分解。矩阵或完整整数搜索超过预算返回
`resource_limit`，不进行不完备扫描后宣称无解。
测试覆盖同一平方自由块中不同整数留数、复代数留数、
构造有理解、齐次共振及预算拒绝。此进展针对基础域 `Q(x)`，
尚不等于高层微分塔中的一般参数化 RDE。

严格积分入口现将单个超指数项的判定从多项式参数扩展到
`f*exp(g)`、`f,g in Q(x)` 且 `g` 非常数。精确计算 `g'` 后使用
上述基础域参数化 RDE；存在 `c_1!=0` 的解空间方向时还原原函数，
否则在完整分母/次数界内的线性系统无解可返回 `proven_nonelementary`。
这里非恒定有理函数的指数是超指数生成元，不将同一结论套到含
任意对数或代数函数的参数。矩阵及共振搜索预算不足单独返回
`resource_limit`，而不是“非初等”。测试涵盖 `exp(1/x)` 与
`exp(1/(x^2+1))` 的非初等判定、相应对数导数倍数的可积性和小预算拒绝。

指数 Laurent 分支也已扩展到非恒定有理参数 `g in Q(x)`。
通过清分母比较精确识别 `exp(k*g)` 的整数倍关系，将正负次数统一到
`exp(g)` 的 Laurent 系数中，再分别求解 `y_k'+k*g'*y_k=b_k`。

相关指数如 `exp(g)` 与 `exp(2*g)` 也可先归一化并在同一换元中完成，
不消耗额外的递归层数。缺少链式因子、系数依赖 `x` 或超出次数预算时
仍返回未知或资源限制，不能据此声称非初等。
相关指数的参数还可含与 `x` 无关的精确加数：先从参数提取该加数，
将 `exp(g(x)+a)` 精确化为 `exp(a)*exp(g(x))`，再检验剩余有理函数参数的
比例关系。符号系数的一次及二次分母分别用精确部分分式重构验收，
并记录可能退化的非零条件；近似偏移不进入该符号常数域路径。
单个指数生成元的参数若有与 `x` 无关的精确导数 `a`，同样可在符号
一次/二次分母下置 `t=exp(g(x))`：先在常数系数有理域积分，再将原函数
除以 `a`，并记录 `a≠0` 的条件。例如 `exp(a*x+b)` 的二次分母可返回
泛型初等原函数；`a=0` 等退化特化需要单独求值，不能从泛型公式代入。
多个符号仿射指数也可先比较斜率：只有各斜率之比化成精确有理数，
并且重新验证比例恒等式时，才用共同分母构造最细的指数生成元。
符号偏移作为常量因子保留；分数与负斜率同样受次数预算约束。
例如 `exp(a*x)` 与 `exp(2*a*x+b)` 可合并，而独立的 `a,b`
不能仅凭形式猜测 `exp(a*x)` 与 `exp(b*x)` 有关系。
换元后若全部系数都是精确有理数，优先使用完整有理函数积分器及其
Hermite/`LogRootSum` 证书；符号常数系数再进入已证明的一次、二次
部分分式分支。这样负判别式及重复数值分母不依赖根式的打印形状。

`t=z-x` 将 `x` 与 `z` 表为 `Q(t)` 中的有理函数，乘入 `dx/dt` 后调用有理函数
积分器，再以 `t=y/sqrt(a)-x` 代回。只在回代结果
通过原变量精确求导验证时接受。此算法处理的是该 genus 0 曲线上的有理微分；
它仍受当前有理函数因式分解/对数根和能力限制，不覆盖高次代数曲线、一般
非平方首项系数的二次根式或代数层非初等性证明。

primitive 层已实现有限和 `Σ_r x^r P_r(t)`，其中 `P_r∈Q[t]`，生成元

## 1. 目标与交付边界

Risch 积分需要同时回答两个问题：能否构造初等原函数；如果不能，是否能证明不存在初等原函数。有限次数的模式匹配、待定系数搜索或分部积分不足以完成第二个问题。

分三层交付：

1. **R0：完备的有理函数后端。** 支持 `Q(x)`，以及明确声明、可有效运算的常数域上的有理函数；高次分母不再依赖根式求根。
2. **R1：受支持的纯超越初等扩张塔。** 支持由有理函数、指数、对数组成的正规微分域塔，包含递归 Risch 微分方程、参数化求解和初等可积性判定。每种塔必须通过常数域与生成元依赖检查；未通过检查的输入不属于判定范围。
3. **R2：代数扩张及混合扩张。** 实现代数函数域运算、局部归约、对数部分判定，以及代数与超越层相互递归的完整依赖。R2 是单独的大阶段，不能在实现几个根式积分规则后宣称完成。

首个实用版本以 R0 和 R1 的受限子集为目标。正式文档必须列出已完成的子算法与支持域，不笼统声称“完整 Risch”。

不纳入核心目标：定积分路径与奇点分析、数值积分、一般特殊函数积分、任意用户函数、含 `abs`/分段/取整的全局可积性判定。现有 `Ei`、`erf` 等规则仍由通用积分入口使用，但不参与初等可积性的证明。

| `cas/test/test_cas.cpp` | 有理式、根式、超指数、符号参数和 ODE 回归 | 保留全部既有测试，补充独立 Risch 测试 |

现有核心使用共享、不可变 DAG；新算法应在独立域表示内计算，最终一次性构造表达式。现有 `numeric_value` 同时容纳精确数与近似数，不能仅凭类型名称判断系数是否可用于证明。

### 2.2 必须新增的基础设施

- 有效常数域及三态零判定；“没有化简为零”不能解释为非零。
- 递归微分域塔，不再把所有下层系数当作导数为零的表达式。
- 生成元关系检查、正规塔条件及不引入新常数的证明或受限准入规则。
- RDE 的通用分母界、次数界、共振情形和参数化求解。
- 任意次数代数常数、精确根选择与有限根求和表示。
- 可以独立重放的归约记录及非初等性证据。
- 分支条件、资源耗尽和算法未实现的独立返回语义。

当前 `factor` 的有限搜索未找到因子不等于不可约证明，详见 [FACTORIZATION.md](FACTORIZATION.md)。新后端不能依赖此结果来证明某个扩张是域。

## 3. 数学约定与正确性契约

### 3.1 输入域与常数问题

使用特征零微分域 `(K,D)`，`D=d/dx`，常数域记作 `C={a∈K | D(a)=0}`。基础层为 `K0=C(x)`。

第一版严格模式的 `C` 从 `Q` 开始，随后支持有效表示的代数数域。符号参数采用 `Q(a1,...,am)` 的泛型语义时，必须显式声明它们代数独立，并记录求解中使用的非零条件；不自动宣称结果覆盖所有参数特化。

“不含 x 的任意 DAG”只能视为候选常量，不能自动视为零判定、因式分解和代数关系均可判定的系数域。例如未指定关系的 `ln(2)`、`pi`、多个指数常数，需要受限域模型或返回 `unknown`。禁止借助浮点近似证明精确非零。

### 3.2 Liouville 形式与证明边界

初等可积性判定围绕以下形式展开：

```text
f = D(v) + Σ c_i * D(u_i)/u_i,     D(c_i)=0.
```

在相应定理假设下，`v`、`u_i` 位于适当的代数扩张中；纯超越算法须用相应下降结论将问题转为可计算的子问题。不能一开始就假定所有对象都属于输入域，也不能把“输入域内找不到原函数”当成“任何初等扩张中都不存在”。

实现时每个判定分支都附带所用定理、适用前提和完整的失败条件。理论路径可参考 Bronstein 的教程，但此文档给出的工程拆分和接口是本项目的设计选择。[Symbolic Integration Tutorial](https://www.math.kobe-u.ac.jp/HOME/taka/2007/knx/bronstein-tutorial-issac98.pdf)

### 3.3 统一归约不变量

所有阶段输出保持：

```text
f = D(elementary_part) + remainder
```

`elementary_part` 可以包含精确对数根和，但不能包含新的未求值积分或特殊函数。`remainder` 必须在同一已声明微分域中精确表示。

- 成功：`remainder=0`，且全部条件明确。
- 非初等：完整判定证明剩余部分没有初等原函数。
- 未完成：只保证分解恒等式，不对剩余部分作不存在性断言。

对和式不能简单合并各项的非初等标签：两个非初等余项可能相消。必须在共同塔中合并并规范化剩余项，然后重新判定。

### 3.4 实数、复数与分支

内部使用形式微分域语义，解析解释为避开奇点并固定分支后的局部恒等式。显示层按用户域选择 `log`、`ln(abs(...))` 或实数反三角形式，不能把局部正确表述为跨奇点的全局原函数。

- 在实数区间内，`1/x` 可显示为 `ln(abs(x))`；复数局部原函数使用 `log(x)`。
- `log(a*b)=log(a)+log(b)`、`log(exp(u))=u` 不能无条件用于全局分支转换。
- `sqrt(x^2)=x` 必须有适当符号条件。
- 若现有构造器已丢失输入分支信息，新入口只能保证收到的 DAG 的约定语义；要支持更强的全局语义，需要另行完善构造器和假设系统。

## 4. 结果类型与调用架构

### 4.1 新增诊断接口

以下为 C++17 风格的接口草案，不是可直接编译的声明：

```cpp
enum class risch_status {
    elementary,
    proven_nonelementary,
    unsupported,
    undecidable_constant,
    resource_limit,
    verification_failed
};

struct risch_result {
    risch_status status;
    exact_expr elementary_part;
    exact_expr remainder;
    condition_set conditions;
    certificate_handle certificate;
    risch_diagnostic diagnostic;
};

risch_result integrate_elementary(
    const exact_expr& f,
    const exact_expr& x,
    const risch_options& options);
```

每个有效输入都返回有效的 `elementary_part` 与 `remainder`，未取得进展时为 `0` 与原输入。非法变量、不同 context、损坏句柄沿用现有参数异常，不混入数学判定状态。

`proven_nonelementary` 表示 `remainder` 已证明非初等，从而原输入也无初等原函数；此时仍可返回已提取的初等部分。`unsupported` 等状态可以携带已经验证的部分结果。

条件不为空时，成功或否定结论仅在这些条件下成立。调用方如果不能呈现条件，就不能静默丢弃它们；应退回形式积分或已有的条件安全结果。

### 4.2 通用积分入口的分派

```text
检查输入与语义
  → 可精确验证的廉价初等规则
  → integrate_elementary / Risch 后端
  → 按策略尝试 Ei、erf、Si、Ci 等特殊函数
  → 初等部分 + 未求值剩余积分
```

迁移初期默认入口保持现有分派，新接口独立启用；回归稳定后再替换顺序。规则返回的候选只有通过精确验证才能进入诊断接口的 `elementary` 状态。特殊函数原函数可以是通用入口的成功结果，但其存在不改变初等积分接口的否定结论。

现有调用形态 `exact_context::integrate`、自由函数 `integrate`、`expr` 包装与 `dsolve` 保持兼容。不定积分接口仍省略任意积分常数，`dsolve` 继续负责生成自己的自由常数。

## 5. 精确代数基础层

### 5.1 系数域接口

系数域需提供 `add/sub/mul/inv/normalize/is_zero/equal`，并声明可用的因式分解、代数扩张和线性代数能力。`is_zero`、`equal` 使用 `yes/no/unknown`；求逆必须先确认非零或建立条件。

`Q` 中所有这些基本判定都是确定的。符号参数域中，规范分子为零决定泛型零；参数特化导致分母为零属于条件管理问题。任意表达式系数的未知零性必须沿调用链传播。

### 5.2 多项式和有理函数

- 第一版优先稠密一元多项式，保持与现有表示接近；根据真实基准决定是否增加稀疏表示。
- 统一零多项式、次数、首项和 monic 规范；零多项式不得按无符号次数参与循环。
- 实现欧几里得除法、精确整除、GCD、扩展 GCD、平方自由分解、resultant 与 subresultant PRS。
- 有理函数固定为互素分子/分母，分母首一；系数域未知时禁止伪造这种规范形。
- 明确区分形式偏导 `∂/∂t` 与微分域导子 `D`。
- 分式消元优先消除公因子，必要时采用 fraction-free 方法控制系数膨胀。

测试必须包括 `a=b*q+r`、Bezout 恒等式、平方自由因子重构、逆元恒等式，以及参数退化产生的条件。

## 6. R0：完整有理函数积分

### 6.1 Hermite 归约

输入 `f=A/B∈C(x)`，先约分与长除，再利用平方自由分解及扩展 GCD 消除重复极点，得到：

```text
A/B = D(U) + V/W
deg(V) < deg(W), gcd(V,W)=1, gcd(W,W')=1.
```

多项式部分的积分可以包含在 `U` 内。每次更新都记录重构恒等式，不要求先把 `B` 分解成一次、二次因子。平方自由分解不等于不可约因式分解。

验收包含高次重复分母、非真分式、输入先有公因子、常量分母及零输入。不得沿用固定次数试探作为数学上的终止依据；次数上限只属于资源预算。

### 6.2 对数部分与高次根表示

对平方自由余项 `V/W`，已实现不展开代数根的精确表示 `LogRootSum(V,W,x)`：

```text
sum_{W(alpha)=0} V(alpha)/W'(alpha) * ln(x-alpha)
```

构造器验证精确有理系数、`deg(V)<deg(W)` 和 `gcd(W,W')=1`；对 `x` 求导按节点定义
严格返回 `V/W`。当前先保留根和整体，不做高次根式展开或数值求值。节点已接入
hash-consing、打印、求导、代换、化简及 arena compact。低次根仍优先输出已有根式或
`atan` 形式。后续若要把根和按相同留数分组并展开，可采用 Rothstein–Trager 及
LRT 风格的子结式构造：

```text
R(z) = resultant_x(W, V - z*W')
```

后续的留数分组/展开算法可由 `R` 的不同根给出留数，再在相应常数扩张中构造与
`gcd(W,V-c*W')` 对应的对数因子。届时需处理内容因子、重根、多个极点具有相同
留数，以及子结式在根处退化的情形。

新增内部对象：

- `AlgebraicConstant`：最小多项式、所属常数域、隔离区间或复隔离区域；不依赖近似排序识别根。尚未实现。
- `LogRootSum`：已实现为以精确分子、平方自由分母及积分变量为操作数的紧凑 DAG 节点；高次根和的近似求值及按留数分组展开尚未实现。

根和是有限个初等项的精确表示，不是未求值积分。当前用对数导数的部分分式恒等式作为求导定义；构造时已约分并验证分母平方自由，因此无需假定分母不可约或在可约商环中随意求逆。

DAG 已接入 opcode、hash-consing、结构比较、打印、求导、替换、变量依赖、arena
compact 与通用化简/展开。数值求值和 parser 对打印形式的反解析暂未实现。

低次根优先输出已有根式或 `atan` 形式。`1/(x^5-x+1)` 之类有理函数必须可以返回精确初等结果，不得因没有五次根式公式而返回非初等。

**R0 完成标准：** 在已声明有效常数域、根表示可用且预算充足时，任意有理函数都返回可验证的初等原函数。

## 7. 微分域塔构造与规范化

### 7.1 层结构

```text
K0 = C(x), D(x)=1
Ki = K(i-1)(ti)

primitive:   D(ti)=ai，ai 属于下层
             对 log(ui)，ai=D(ui)/ui
exponential: D(ti)=ai*ti，ai 属于下层
             对 exp(ui)，ai=D(ui)
algebraic:   Pi(ti)=0，后期支持
```

先实现由对数引入的 primitive 层，不将任意形式积分直接作为新生成元。每层保存类型、下层 ID、导数数据、原 DAG 映射、条件和准入证据。

元素用递归的一元有理函数表示。对多项式有：

```text
D(Σ a_j*t^j) = Σ D(a_j)*t^j + Σ j*a_j*t^(j-1)*D(t).
```

因此 `log(x)*exp(x)` 中的 `log(x)` 系数不能按常数处理。

### 7.2 建塔步骤

1. 检查精确数值、积分变量和语义模式。
2. 遍历 DAG，收集依赖变量的指数、对数及代数节点。
3. 按依赖拓扑排序，同层候选用稳定规范序排序。
4. 将 `log2`、`log10` 在相应常数域可处理时转为自然对数；`e^u` 统一为 `exp(u)`。
5. 检查候选生成元是否可由已有塔表示，复用同一生成元或转为已有元素。
6. 对无法证明是合法新超越生成元的情形返回明确的 unsupported/unknown，不盲目新增独立变量。
7. 检查每层导子闭合性、关系一致性和不引入新常数的前提。
8. 验证输入 DAG 到塔的转换和反向输出保持约定语义。

典型关系包括 `exp(2*x)=exp(x)^2`、`exp(-x)=1/exp(x)`；`exp(x/2)` 与 `exp(x)` 应统一到较细的生成元。`log(x^2)` 与 `2*log(x)` 的关系涉及分支常数，应按语义策略处理，不能直接当成两个独立超越元。

一般指数乘法关系、对数关系和常数扩张检查需要递归求解能力。为避免启动依赖循环，第一版只接受具有可验证构造证据的塔；其余返回未支持。后续使用下层的对数导数判定、整数关系和参数化求解扩大准入范围。

当前增加了底层为 `Q(x)` 的 primitive 导数关系证书：对所有
`D(t_i)` 联立求解 `D(y)=sum(c_i*D(t_i))`，保留参数 RDE 的
完整核并排除所有 `c_i=0` 的齐次常数方向。每条保留关系都重新
验证有理函数恒等式，输出精确 `c_i` 和有理 `y`。空关系基表示
在该有理下层不存在非零常数线性组合的有理原函数；资源不足或
下层含超越函数会明确失败，不冒充独立性证明。
多 primitive 正向求解已调用该检查；有关系的生成元仍可用于
逐系数验证的正例，但不会由其搜索失败推出非初等。证书只确定
`sum(c_i*t_i)-y` 是常数，尚未确定分支常数，也不自动替换表达式。
回归包含 `log(x)`、`log(x+1)` 及 `log(x/(x+1))` 的导数关系。

## 8. R1：超越层归约与递归积分

### 8.1 normal / special 分母

在 `K[t]` 中按完整导子 `D` 区分因子：normal 因子满足 `gcd(p,D(p))=1`；special 因子满足 `p | D(p)`。一般平方自由分母需要按相应算法拆成这些部分，不能把普通 `∂p/∂t` 的平方自由分解直接当成微分分解。

- normal 的重复极点进入微分 Hermite 归约。
- simple normal 部分进入微分留数与对数部分判定。
- special 部分进入对应扩张类型的专门算法。
- 多项式部分进入次数归约和低层 RDE。

例如指数层中 `t` 是 special，负幂 `t^-m` 是合法 Laurent 项；不能因为没有普通有理函数式的处理分支而把它判为非初等。

每个过程输出 `D(g)+r` 的证据。微分留数判定需要检查留数是否为常数，并在必要的代数常数扩张中构造对数项；直接套用 R0 的 `W'` 公式并不足够。

### 8.2 primitive / 对数层

当 `D(t)=a∈K` 时，先归约有理部分，再对 `Σ b_j*t^j` 从最高次数递归消去。

若候选为 `Σ y_j*t^j`，系数满足：

```text
D(y_j) + (j+1)*a*y_(j+1) = b_j.
```

下层积分得到的自由常数会影响下一层系数，必须保留为参数并统一求解。不能逐项取一个任意原函数、丢掉积分常数后继续，也不能假定输出次数必定不超过输入次数：次数上界必须由对应算法给出。

此阶段依赖参数化 RDE、下层初等积分与对数导数关系求解。建议先完成单层 `log(x)`，再支持 `log(log(x))`、有理函数的对数和指数/对数混合塔。

### 8.3 exponential 层

当 `D(t)=a*t` 时，对 Laurent 多项式项 `b_m*t^m`，候选 `y_m*t^m` 导出：

```text
D(y_m) + m*a*y_m = b_m.
```

`m=0` 递归到下层积分，正负 `m` 都进入下层 RDE。非 Laurent 的一般有理部分先完成 normal/special 归约和留数判定。

先覆盖 `C(x,exp(g(x)))`，再逐步覆盖 `C(x,log(x),exp(x))` 与嵌套指数。单个 RDE 无解只有在完整归约定理说明该方程是必要条件时，才可以升级为积分非初等结论。

## 9. Risch 微分方程求解器

### 9.1 输入、输出与算法顺序

核心方程为：

```text
D(y) + a*y = b,     a,b∈K，寻找 y∈K.
```

内部状态为 `solved / no_solution / unsupported / unknown / resource_limit`。`no_solution` 必须有完整界与不可解证据；固定试探次数失败只能返回未完成。

实现顺序：

1. 规范化 `a,b`，单独处理 `a=0`、`b=0` 与齐次解空间。
2. 用 normal 极点赋值推导分母界，记录每个不可约因子或平方自由块的极点阶约束。
3. 对 special 因子推导额外界；普通极点公式不能覆盖它们。
4. 令 `y=z/q`，清分母得到多项式微分方程。
5. 分析无穷远最高次项，推导次数界；处理首项抵消、整数共振和需要下层方程判定的例外。
6. 在已证明的界内求解多项式方程，系数问题递归到下层。
7. 代回 `D(y)+a*y-b` 精确归零。

基础域 `C(x)` 中可将有限未知量交给精确线性代数。在更高层，系数属于微分域，不能把它们当成常数直接用普通 Gaussian 消元替代递归微分方程求解。

### 9.2 参数化版本

需要求解：

```text
D(y) + a*y = Σ c_i*b_i,     c_i∈C.
```

输出是 `(y,c_1,...,c_n)` 解空间的一组常数域基，而不是单个特殊解。应覆盖齐次解、零右端、自由参数和退化秩。

对数关系判定所需的整数系数条件也须单独处理；常数域上的线性空间求解不能自动代替整数关系求解。未实现相关关系算法时限制塔准入，不能假装生成元独立。

### 9.3 初期 RDE 验收

| 方程 | 预期 |
| --- | --- |
| `y'+y=x`，`y∈Q(x)` | `y=x-1` |
| `y'+y=x/(x+1)^2` | `y=1/(x+1)` |
| `y'+2*x*y=2*x` | `y=1` |
| `y'+2*x*y=1` | 完整算法证明无有理解 |
| `y'+a*y=1` | 泛型 `a!=0` 时 `1/a`；`a=0` 时 `x` |
| 人为降低分母/次数预算 | `resource_limit`，禁止 `no_solution` |

可参考 SymPy 的 RDE 实现梳理分母归约、次数界与多项式求解的接口分工，但本项目需针对自己的系数域和证据结构重新实现。[SymPy rde.py](https://github.com/sympy/sympy/blob/master/sympy/integrals/rde.py)

## 10. 三角、双曲与一般幂

待复代数常数和指数塔稳定后，加入规范转换：

```text
sin(u)  = (exp(i*u)-exp(-i*u))/(2*i)
cos(u)  = (exp(i*u)+exp(-i*u))/2
sinh(u) = (exp(u)-exp(-u))/2
cosh(u) = (exp(u)+exp(-u))/2
```

同一 `u` 的正负指数必须共用生成元。`tan`、`tanh` 转为这些生成元的有理式；整数倍频率先做关系消除，非整数关系需要常数域支持。

严格积分器现对两个基础有理三角子域直接做半角有理代换：`Q(sin(x),cos(x))`
用 `t=tan(x/2)`，`Q(sinh(x),cosh(x))` 用 `t=tanh(x/2)`。代换微分后要求
输入成为精确 `Q(t)` 有理函数，再调用有理函数积分器；验证其参数原函数后才
回代。整数倍角 `n*x` 用二项式递推转为同一参数域的有理函数，频率关系因此在
代换时显式消除。频率上限由 `maximum_degree` 预算决定（代换多项式最高可达
`2*|n|` 次），不再固定为 32。该路径覆盖 `1/(1+sin(x)+cos(x))`、三倍角同形
输入、默认 64 次预算下的 17 倍角输入、更高预算下的 40 倍角输入，
以及对应的双曲表达式。同分母有理和在解析时直接合并分子，
避免约分前无谓的分母次数翻倍。暂不接收混合圆/双曲
生成元、非整数/复合角或其它下层系数。

反三角及反双曲函数可按固定分支转换为对数/根式，但会引入代数函数扩张，因此不能在 R2 之前承诺一般支持。现有直接规则继续保留。

`u^v` 的策略：整数幂直接处理；有理指数优先进入代数扩张；一般指数只能在明确局部分支下转换为 `exp(v*log(u))`。常数底数的 `a^x` 需要处理 `a=0`、`a=1` 和 `log(a)` 所属常数域，不能无条件除以 `log(a)`。

实数结果美化放在证明完成之后，只有能验证的共轭配对才改写为实对数或反三角式；美化失败保留正确的复形式。

## 11. R2：代数函数与混合扩张

必须区分：R0 中的“代数常数根”满足 `D(alpha)=0`；代数函数根 `alpha(x)` 通常导数非零。前者完成不代表后者已实现。

### 11.1 有效代数函数域

对不可约、可分的关系 `P(x,alpha)=0`，在已有域上实现模最小多项式约简、逆元、范数、迹及扩张兼容性。导子由关系导出：

```text
D(alpha) = -D_coeff(P)(alpha) / (∂P/∂alpha)(alpha).
```

`D_coeff` 只作用于系数。必须先确认所用关系定义的是域；可约多项式应分支、分解或采用正确的商代数算法。

### 11.2 逐级实现路线

1. 先将现有二次根式规则纳入统一域内验证，覆盖 `sqrt(P(x))` 的简单情况。
2. 对可参数化的 genus 0 曲线实施有证明的有理参数替换，并验证逆向代入。
3. 实现一般代数函数域的整基或经过证明适用的惰性整基算法、有限点和无穷远局部展开/赋值。
4. 在分歧点也正确执行代数 Hermite 归约，提取精确微分部分。
5. 计算留数与候选对数微分；实现所需的除子、主除子判定和相关有限维计算。
6. 在明确常数域条件下完成剩余第一类/第二类微分与对数部分的初等性判定，不能仅凭“剩余非零”下结论。
7. 实现代数层上的 RDE 与参数化子问题，再与外层对数、指数塔组合。

第 5—7 步是独立研究与实现里程碑，实施前补充具体算法出处、终止条件及可计算性前提。如果相关子算法尚不可用，API 必须返回 unsupported。

区分用例：`1/sqrt(1-x^2)` 有初等原函数；`1/sqrt(x^3-x)` 在相应非奇异代数曲线上属于非初等情形。第二个用例不能因为现有二次根式规则失效就被标记为已证明非初等。

## 12. 验证、证据与错误处理

### 12.1 正向验证

采用两层检查：

1. **域内检查：** 在输入塔及结果引入的合法扩张中规范化 `D(F)+r-f`，证明为零。
2. **DAG 检查：** 将结果转回表达式后调用既有求导，并重新导入域内验证，捕获构造、符号或转换错误。

通用 `simplify(diff(F,x)-f)` 可作快速检查，但未化简为零不是反证。数值采样仅用于发现错误，不作为证明。针对复分支或特殊函数的采样避开极点与分支切割，并明确其辅助性质。

### 12.2 否定证据

建议证据包括：

- 塔和常数域标识、生成元准入证明及全部假设。
- Hermite/多项式归约的重构恒等式。
- 阻碍初等性的规范剩余项及所用判据。
- RDE 分母界、次数界、例外分支检查，以及最终线性/递归系统不可解证据。
- 算法版本、子问题引用及预算完成标志。

验证器重放代数恒等式与边界推导，不依赖搜索器的“失败”布尔值。首版可先实现内部结构化证据，不必立即设计公开序列化格式；在否定证据链完成前，统一返回未完成状态。

### 12.3 资源与诊断

统一预算包括塔高、多项式次数、总项数、系数位数、矩阵规模、PRS 中间项规模、DAG 节点增量和工作量计数。时间限制可补充，但测试优先使用确定性工作量预算。

诊断应指出失败位置，如“第 3 层常数关系未知”“RDE special 分母分支未实现”“resultant 超过项数预算”。任何预算耗尽都不得转为非初等结论。

缓存键包含 arena 身份、变量、域塔、假设与语义模式；arena compact 后不得继续用裸 node ID 命中旧缓存。跨会话缓存须使用稳定内容标识。

递归求导和构造可能使 arena 存储重分配，不能跨新增节点操作保存易失效的 child 指针或节点引用。新模块应保持现有代码中复制节点和操作数的安全习惯。

### 13.2 失败语义与退化测试

- 近似系数进入严格模式：明确拒绝或返回 unsupported，不自动有理化。
- 未声明的常数关系：unknown/undecidable_constant，不作为非零主元。
- `exp(a*x)`、`1/(a*x+b)`：覆盖 `a=0` 与泛型非零条件。
- `a^x`：覆盖合法非零底数、`a=1` 以及未定义情形。
- 随机重排加法/乘法和改变符号名：状态与数学结果不变。
- 输入具有相关指数生成元：避免错误的独立变量建塔。
- 显式注入低预算：只能得到 resource_limit 或已验证的部分结果。
- 两个非初等余项相消、以及初等项加非初等余项：检查合并语义。
- `abs(x)`、未知函数、未实现代数层：不得给出无依据的非初等结论。
- 跨 context 句柄、arena 压缩、深层 DAG：覆盖有效性和缓存生命周期。

### 13.3 性质测试、对照与性能

从受支持塔随机生成 `F`，取 `f=D(F)` 后积分，检查结果的导数等于 `f`，不要求恢复同一个字符串。生成器要控制塔合法性与资源，不生成未经证明的独立关系。

对 RDE 随机选择 `a,y` 并生成 `b=D(y)+a*y`，检查能找回某个解；另建立人工证明的无解语料，避免只测正例。

可使用固定版本 SymPy 作为离线对照，记录版本与输入。其 Risch 接口区分证明非初等与尚未实现，但实现范围有限，因此对照工具的失败不能用作本项目的否定证明。[SymPy 积分文档](https://docs.sympy.org/latest/modules/integrals/integrals.html)

性能语料按有理分母次数/重数、塔高、项数、参数数量分类，记录耗时、峰值节点数、系数位数、GCD/PRS 次数及缓存命中。先建立基线，再选择真实瓶颈优化；CI 使用确定性规模和工作量上限，避免仅用墙钟时间判定。

建议按以下小步 PR 开始：

1. 引入结果状态与严格入口，尚未覆盖的输入全部明确返回 unsupported。
2. 抽取现有精确一元多项式工具并补齐 GCD/Bezout 不变量。
3. 实现不依赖低次因式分解的有理 Hermite 归约。
4. 实现代数常数与有限对数根和的最小完整生命周期。
5. 接入 RT/LRT，完成 R0；随后启动微分域塔和通用 RDE。

不要第一步整体改写 `exact_context::integrate`，也不要先扩充大量匹配规则来代替基础层。每个 PR 都应说明新增支持域、未知分支、验证方式和资源行为。

## 15. 主要风险与最终完成标准

| 风险 | 应对 |
| --- | --- |
| 任意表达式常数的零判定不完备 | 明确有效常数域；unknown 全链路传播 |
| 生成元存在隐含关系 | 正规塔准入证据；受限输入先行 |
| 错把搜索失败当无解 | 只有完整界和证据才能返回否定状态 |
| 高次根式输出爆炸 | 精确根和、迹与子结式表示 |
| 参数除零、分支条件丢失 | 条件是结果的一部分；不支持呈现则保留形式积分 |
| RDE 系数增长与递归循环 | 规范表示、缓存、递减度量和显式预算 |
| 通用化简影响证明可靠性 | 以域内规范形和可重放证据为准 |
| DAG 新节点仅支持打印 | 将求导、替换、compact、依赖分析纳入同一验收 |
| 代数部分工作量低估 | 独立里程碑，公开尚未完成的子算法 |

每个发布层级都必须满足：

- 支持域和前提被明确描述，并可由入口检查。
- 成功结果通过精确求导验证；部分结果满足分解恒等式。
- 非初等结论有可重放证据，资源失败和未实现绝不伪装成证明。
- 参数条件与局部分支语义能够传递到调用者。
- 现有积分、表达式、计算器及 `dsolve` 回归无退化。
- 新源文件进入全部相关构建入口，性能与资源行为具有可重复基线。

只有 M9/M10 所需的代数与混合子算法也完成，并且所有常数域与表示前提都得到满足后，才考虑使用“完整 Risch 实现”这一表述；任何时候都应同时附上精确适用范围。
